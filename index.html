Sur Quest 2

  1. Le plus simple : publiez sur GitHub Pages (HTTPS inclus). Dans le casque, ouvrez le Navigateur (icône globe) et allez sur https://votre-compte.github.io/nom-du-repo/.
  2. Ou, en local : npm run dev:https, même Wi‑Fi, puis l’IP affichée (ex. https://192.168.1.20:43221). Acceptez le certificat local.
  3. Le badge doit indiquer Quest détecté. Choisissez un film, puis Entrer en VR. Autorisez la session immersive.
  4. Visez le panneau doré avec le rayon, validez avec la gâchette. Bouton A : lecture. Bouton B : masquer le panneau.
  5. Pour un NAS (SMB) : lancez npm run dev:https sur le PC, ouvrez cette adresse dans le Quest, puis remplissez Disque réseau. GitHub Pages ne peut pas parler SMB.
