Sur Quest 2

  1. Ouvrez le navigateur Meta Quest (pas l’application TV).
  2. Entrez l’adresse HTTPS de cette page, ou ajoutez-la à vos applications (PWA).
  3. Choisissez un film et un mode, puis appuyez sur Entrer en VR.
  4. Visez le panneau doré avec le rayon, validez avec la gâchette. Bouton A : lecture. Bouton B : masquer le panneau. Stick : avance / volume.
