Projection

Sur Quest 2

  1. Le bouton Preview de Cursor ne s’ouvre pas dans le casque. Il faut une adresse HTTPS que le Quest peut joindre (votre PC en Wi‑Fi, ou un site déployé).
  2. Sur l’ordinateur, dans ce projet : npm run dev:https. PC et casque sur le même Wi‑Fi. Notez l’IP réseau affichée (ex. https://192.168.1.20:43221).
  3. Dans le casque, ouvrez l’app Navigateur (icône globe dans la bibliothèque — pas TV, pas YouTube). Tapez cette adresse.
  4. Si un avertissement de certificat apparaît, continuez quand même (certificat local). Choisissez un film, puis Entrer en VR. Autorisez la session immersive.
